# PyFlask-TsReact

Python(Flask)+TypeScript(React)を組み合わせたアプリケーション実装サンプル

## 🛠 技術スタック

### Frontend

- **Framework:** React 18 (ビルドツール: [Vite](https://vitejs.dev/))
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v3)
- **UI Components:** [Shadcn/ui](https://ui.shadcn.com/)
- **Routing:** React Router v6
- **Authentication:** AWS Amplify (v6)

### Backend (API)

- **Framework:** Python / Flask
- **Authentication:** JWT (JSON Web Token) 検証

### Infrastructure / Auth

- **Identity Provider:** Amazon Cognito (User Pool)
- **IaC:** (Terraform / AWS CDK / CloudFormation 等を想定)
